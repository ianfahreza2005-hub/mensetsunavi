# Audio

Folder rekaman suara (belum diisi).

- `narator/` — narasi `.mp3`, nama file sesuai field `file` di `data/content.js` (contoh `s02_01.mp3`).
- `musik/bgm.mp3` — musik latar (opsional; tanpa file ini dipakai musik sintetis WebAudio).

Setelah rekaman tersedia, ubah `MN.Config.useRealAudio` menjadi `true` di `js/core/audio.js`.
